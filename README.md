# sleep is all you need

[View the project →](https://caozhuozi.github.io/10y/)

If only someone—anyone—had told me, in primary school, middle school, or
university:

> Go to sleep. Sleep is ten thousand times more important than whatever you
> are doing right now.

How I wish someone had.

This ten-year personal project is the reminder I wish I had been given.

One day, one tile. Ten years, in two five-year chapters. The first chapter is
2026–2030.

sleep is all you need.
